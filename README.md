# Comanda · Todo Chévere

Asistente con IA que atiende por chat (texto, audio y foto) los pedidos de una pizzería, los valida contra el menú real, cobra con Mercado Pago y los envía a un panel de cocina en tiempo real.

Hackatón "Del problema al servidor" · DonWeb Day Rosario 2026.

**Stack:** React 19 · Node/Express · Supabase (Postgres + Realtime) · OpenAI · Mercado Pago.

## Desarrollo

```
cp server/.env.example server/.env   # completar las claves
npm install
npm run dev
```
